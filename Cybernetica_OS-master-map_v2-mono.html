Ядро · таблицы, статусы, принципы

По каким рельсам едут сделки

Ядро — не новая CRM, а эволюция существующих трёх таблиц Александра: в них внедряется статусная модель и карточки. Решение сознательное — не плодить новую систему, пока работает текущая инфраструктура.

Правило конвейера: карточка не переходит на следующий статус, пока не выполнены условия текущего. Напоминания о зависших шлёт система, а не Анастасия. Где скапливаются карточки — смотрит COO еженедельно; целостность статусов и доступов держит Александр.
П1
Нет в карточке —
не существует
Договорённости, условия, документы фиксируются в момент возникновения тем, кто договорился. Восстановление «по чатам» — запрещённый режим.
П2
Нет заявки —
нет платежа
Все исходящие платежи — только через платёжный календарь по заявке в системе. Акцепт — Родион.
П3
Документы — часть
владения ролью
Менеджер владеет не только клиентом, но и документной частью: онбординг, закрывающие, ОРД по своим размещениям. Это KPI, а не просьба.

Системная коммуникация

Ритм вместо прослойки

Иерархию заменяет ритм + общие данные + письменная культура. Правило по умолчанию: сначала карточка, потом чат. Чат — для обсуждения, система — для фактов.

Еженедельно · 45 мин

Общий синк всей системы

Все 11 человек. Статусы из таблиц, не пересказом: где скапливаются карточки, блокеры, решения. Ведёт COO.

Еженедельно

Срез COO

Конвейер по статусам + дебиторка-дашборд + эскалации. Приборная панель внутреннего контура.

Ежемесячно

Родион + COO + Александр

План-факт, загрузка, перераспределение ролей, стоимость менеджмента как метрика с потолком.

Постоянно

Письменная фиксация

Существенные решения — записью в системе. Совместные решения Родион + COO (бюджеты, найм, скидки ниже порога) — тоже письменно.

Каналы

Чат ≠ система

Переписка — для обсуждения и скорости. Всё, что имеет последствия (условия, суммы, сроки), дублируется в карточку в момент возникновения.

Работа с Claude

Один чат — один документ

Разборы договоров и задач — отдельными чатами внутри проекта. Всё, что должно помниться всегда, — в файлы проекта, а не в переписку.

AI-контур

AI встроен в модули,
а не живёт отдельно

Ключевой принцип: ИИ находит и формулирует — человек решает. Финальная ответственность (подписание, платежи, красные линии) всегда за человеком.

Приоритет 1 дорожная карта готова

AI-сверка договоров

Этапы: эталоны → плейбук с красными линиями → скилл (вход: docx контрагента, выход: tracked changes + протокол разногласий) → регламент. Снимает перепроверку за юристом. Опция второго контура — Noroots (ЕГРЮЛ + СПС).

Приоритет 2 после ядра

Авто-напоминания по статусам

Скрипт по зависшим карточкам: закрывающие, дебиторка, ОРД-дедлайны. Убирает роль «Анастасия-пожарный» окончательно.

Приоритет 3 по мере готовности

Авто-отчёты и проверка цифр

Сборка клиентских отчётов из данных системы + арифметическая сверка перед отправкой: расхождения ловим сами, до клиента.

Правило верификации: каждая ссылка на норму права из AI-разбора проверяется через СПС до использования в переговорах. Решения по красным линиям — всегда человек.
Роадмэп

Три фазы внедрения

Последовательность выбрана так, чтобы каждая фаза снимала конкретную боль сразу, а не строила фундамент месяцами.

I
Снять нагрузку
2–4 недели
  • ОРД/ЕРИР → менеджерам с чек-листом — самый быстрый выигрыш для Анастасии.
  • Объявить команде принципы П1–П3: фиксация в карточках, возврат документов — KPI.
  • Запустить ЭДО-миграцию: список контрагентов, приглашения, ЭДО-оговорка в шаблоны.
  • Довести contract-review до рабочего состояния (этапы 0–2 дорожной карты).
II
Построить ядро
1–2 месяца
  • Статусная модель S1–S7 в таблицы Александра: карточки сделок и контрагентов, поле «условия».
  • Подрядчики-физлица — на платформу самозанятых.
  • Эталонная библиотека договоров с красными линиями (юрист + Родион).
  • Номенклатура в облаке-архиве, привязка к карточкам.
  • Зоны владения менеджеров — в матрицу ролей.
III
Автоматизировать ритм
2–3 месяца
  • Дебиторка-дашборд и платёжный календарь из реестра.
  • Авто-напоминания по зависшим статусам (AI-приоритет 2).
  • Зарплата и кадры — решение по аутсорсу.
  • Стоимость менеджмента — в ежемесячный срез как метрика с потолком.
